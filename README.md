## Veröffentlichen (einmalig)

1. Auf github.com (angemeldet als `stebro01`) ein neues Repository **`stebro01.github.io`** anlegen – **Public**, ohne README.
2. Hier: `git remote add origin git@github.com:stebro01/stebro01.github.io.git && git push -u origin main`
3. Repo → Settings → Pages: Source „Deploy from a branch“, Branch `main`, Ordner `/ (root)`. Nach 1–2 Minuten ist die Seite unter https://stebro01.github.io/ erreichbar.

**Vorher** die Platzhalter „[… eintragen]“ füllen (Impressum: Name, ladungsfähige Anschrift, E-Mail; Kontakt in den Hilfeseiten). Ohne Impressum nicht veröffentlichen.

Änderungen: Datei bearbeiten, committen, pushen – GitHub aktualisiert die Seite von selbst.
